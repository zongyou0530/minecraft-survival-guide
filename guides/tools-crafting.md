## 先認識工作台

大部分工具都需要使用 **工作台（Crafting Table）** 的 3×3 合成格。

- 打開工作台後，依照下方圖案放入材料。
- 圖案可以整體移到 3×3 格子的其他位置；左右鏡像通常也可以。
- 空白格代表不放材料。
- 合成完成後，從右側成品欄拿取物品。

### 圖案符號

| 符號 | 代表材料 |
|---|---|
| M | 工具材料：木材、圓石、銅錠、鐵錠、金錠或鑽石 |
| S | 木棒 |
| I | 鐵錠 |
| C | 銅錠 |
| G | 金錠 |
| D | 鑽石 |
| R | 紅石粉 |
| F | 羽毛 |
| A | 紫水晶碎片 |
| T | 線 |

### 可以使用哪些材料？

| 材質 | M 可以放入 | 說明 |
|---|---|---|
| 木製 | 任意木材木板 | 最初期使用 |
| 石製 | 圓石等石製材料 | 比木製更耐用 |
| 銅製 | 銅錠 | 速度與耐久度介於石製與鐵製之間 |
| 鐵製 | 鐵錠 | 很實用的中期選擇 |
| 金製 | 金錠 | 挖掘速度快，但耐久度低 |
| 鑽石 | 鑽石 | 高階工具 |
| 獄髓 | 不直接合成 | 用鍛造台把鑽石裝備升級 |

注意：銅製工具與銅劍使用和其他材質相同的合成形狀，只要把 M 換成銅錠即可。

## 三、獄髓工具怎麼做？

獄髓（Netherite）工具**不能直接在工作台合成**，必須使用鍛造台（Smithing Table）升級。

每升級一件裝備，需要：
- 1 個獄髓升級鍛造模板（Netherite Upgrade Smithing Template）
- 1 件鑽石工具或鑽石劍
- 1 個獄髓錠

操作方式：

1. 放置並打開鍛造台。
2. 左側第一格放入獄髓升級鍛造模板。
3. 第二格放入要升級的鑽石工具。
4. 第三格放入獄髓錠。
5. 取出獄髓工具。

```text
鍛造台：
[獄髓升級模板] [鑽石工具] [獄髓錠]
                         ↓
                     獄髓工具
```

提醒：升級時會保留原本鑽石工具上的附魔與自訂名稱。模板是消耗品；想升級多件裝備，需要準備多個模板或先複製模板。

## 四、新手最推薦先做哪些？

如果你剛開始生存，不需要一次做齊所有工具。我建議依序製作：

| 優先順序 | 工具 | 為什麼先做 |
|---|---|---|
| 1 | 木鎬 | 取得圓石，開始製作石製工具 |
| 2 | 石鎬 | 挖鐵礦、煤炭等常用資源 |
| 3 | 石斧 | 快速收集木材 |
| 4 | 石劍 | 提升基本戰鬥能力 |
| 5 | 鐵鎬 | 採集鑽石等更高階礦物 |
| 6 | 水桶 | 探洞、處理岩漿與水流 |
| 7 | 盾牌 | 降低骷髏等敵人的威脅 |
| 8 | 鑽石鎬 | 挖黑曜石、進入後期發展 |

## 五、常見問題

**Q：為什麼我有鐵礦，卻不能直接做鐵鎬？**

要先把鐵礦放進熔爐燒成鐵錠，才能拿鐵錠合成鐵鎬。

**Q：為什麼木鎬挖不到鑽石？**

木鎬等級不足。鑽石礦需要鐵鎬或更高等級的鎬子才能取得鑽石。

**Q：銅工具值得做嗎？**

值得當作石製工具之後、鐵製工具之前的過渡選擇。官方說明指出銅裝備的速度與耐久度介於石製與鐵製之間。

**Q：獄髓工具可以直接合成嗎？**

不行。要先有鑽石工具，再用鍛造台、獄髓升級模板和獄髓錠升級。

**Q：工作台裡找不到配方怎麼辦？**

打開工作台左側的配方書，搜尋物品名稱；部分配方要先取得相關材料才會解鎖。也可以直接依照本頁圖案擺放。
