一般玩家認定的主線破關，就是擊敗終界龍（Ender Dragon）。

但 Minecraft 是沙盒遊戲，並沒有真正的遊戲結束。擊敗終界龍後：

1. 會出現終界龍死亡動畫。
2. 生成大量經驗值。
3. 中央出口傳送門啟動。
4. 進入傳送門後會看到終末之詩（End Poem）及製作人員名單。
5. 之後仍然可以回到原本的世界繼續生存。

擊敗終界龍只是主線的一個重要終點，之後還有許多內容：

- 探索終界外島（End Cities）。
- 取得鞘翅（Elytra），實現飛行。
- 取得界伏盒（Shulker Box），方便攜帶物品。
- 挑戰凋零（Wither）。
- 建立大型基地、農場、自動化設施。
- 挑戰其他 Boss 和完成進度。

我建議我們把「擊敗終界龍」當成第一個畢業目標，再把鞘翅當成第二個大型目標。

### 5. 保護村莊

晚上會出現殭屍、骷髏、苦力怕等敵對生物。

你要做幾件事情：

1. 在村莊周圍放置火把。
2. 晚上回家睡覺。
3. 不要讓殭屍接近村民。
4. 不要攻擊鐵巨人（Iron Golem）。
5. 保留村民，未來他們非常有用。

為什麼水桶重要？

因為它可以：

- 撲滅身上的火。
- 從高處落下時用水減少摔落傷害（需要練習）。
- 取得水源。
- 製作地獄傳送門時使用。

- 製作水桶。
- 建立農場。

這時候你已經有鐵裝備，可以開始尋找鑽石。

### 鑽石在哪裡？

以現代版本的主世界生成規則來說，鑽石主要分布在地下深處。

推薦從 Y=-58 附近開始尋找。

你可以：

1. 找到安全的洞穴。
2. 往地下深處探索。
3. 使用鐵鎬挖掘鑽石礦。
4. 注意岩漿，千萬不要直接往腳下挖。

### 鑽石優先做什麼？

我建議：

1. 鑽石鎬。
2. 附魔台。
3. 其他鑽石裝備。

鑽石鎬很重要，因為你需要用它採集黑曜石，才能製作一般的地獄傳送門。

不過也可以使用水桶和岩漿的方式，不一定非得先製作鑽石鎬。

這是整個生存流程的重要轉折點。

地獄是一個獨立維度，裡面有很多重要材料，但也非常危險。

### 1. 建造地獄傳送門

需要：

- 至少 10 個黑曜石（最小尺寸）。
- 打火石。

把黑曜石建成門框，再用打火石點燃。

### 2. 進入地獄前的準備

建議攜帶：

- 全套鐵盔甲。
- 鐵劍。
- 弓箭。
- 盾牌。
- 食物至少 32 份。
- 火把。
- 圓石至少 64 個。
- 打火石。
- 一件金製盔甲（推薦金靴子）。

為什麼要穿金裝？

因為豬布林（Piglin）通常會攻擊沒有穿金製盔甲的玩家。穿上一件金裝就能避免一般豬布林因為你沒有穿金裝而主動攻擊。

### 3. 尋找地獄堡壘

### 1. 烈焰粉怎麼取得？

### 2. 終界珍珠怎麼取得？

主要有兩種方式：

- 找到終界使者（Enderman），擊敗牠。
- 使用金錠與豬布林交易，有機會取得終界珍珠。

### 如何找到要塞？

1. 拿著終界之眼。
2. 對著天空使用。
3. 它會飛向要塞所在方向。
4. 跟著它移動。
5. 每隔一段距離再使用一次。
6. 當它開始往地下飛，就代表要塞可能就在下方。

接著往地下挖掘，尋找石磚建築。

你要找的房間是：

![How to make a Minecraft end portal](https://images.openai.com/static-rsc-4/rKatBNRpYW8FwsHl-FRK6qnpeCWNdPd9rqSGJWOmuLMDhGTasPAUarRGc6h0KWSioovKgvBaVK8NXkU6x9DkQPJNlQx7CZC8ZIqhio9HQxT8E_jpWkRwn4BXZRmlTbwkTIrXrEfstPvmrXrSFjZfs6_akJafpPbsHe8GJMgM0-w?purpose=inline)

找到後，把終界之眼放進傳送門框架。

全部啟動後就能進入終界。

重要提醒

不要找到傳送門就馬上跳進去！

因為進入終界後，通常需要擊敗終界龍才能透過中央出口回到主世界。務必先做好準備。
